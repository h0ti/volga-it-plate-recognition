# Распознавание нестандартных ГРЗ РФ — полуфинал Volga-IT 2026

**Автор:** h0ti — [github.com/h0ti](https://github.com/h0ti)

Офлайн-решение для детекции и распознавания российских регистрационных знаков типов
**1**, **1А**, **1Б** с отсевом типа `other`. На вход — каталог изображений, на выход —
CSV формата организаторов:

```
image;plate_num;plate_type;confidence
```

`plate_num` — латиница в верхнем регистре (`A123BC456` / `A123BC45`), нечитаемые
позиции заменяются `#`; `plate_type` — `type1`, `type1a`, `type1b`, `other`.

## Результаты

Проверка на **ручной разметке реальных кадров** (`dataset/real_review_inbox/review.csv`,
164 кадра, 184 знака). Независимого теста организаторов в репозитории нет, поэтому
сквозные метрики считаются только по этой разметке.

| Метрика | Значение |
|---|---|
| Детекция знака, IoU ≥ 0.5 | **95.7 %** (176/184) |
| Верный тип среди найденных | **99.4 %** (175/176) |
| OCR по эталонному кропу, точное совпадение | **36.4 %** (67/184) |
| OCR по эталонному кропу, совпавших символов | **58.6 %** (877/1497) |
| Сквозное совпадение номера и типа (production-пайплайн) | **32.9 %** (54/164) |
| OCR на отложенных 40 кадрах (не участвовали в обучении) | **22.5 %** точных, **47.9 %** символов |
| Полный прогон по каталогу (498 файлов, с чтением с диска) | **31.3 мс/кадр** (RTX 4060) |
| Чистые вычисления без I/O | 20–43 мс/кадр (зависит от доли кадров с повторным проходом 960 px) |

Честные оговорки:

- 137 из 184 кропов участвовали в обучении OCR, поэтому метрика «36.4 %» оптимистична;
  цифра **22.5 %** на 40 отложенных кадрах — более честная оценка качества номера.
- Сквозная метрика ниже OCR-метрики, потому что рамка детектора теснее ручной разметки;
  в пайплайне это компенсируется подбором отступов и нормализацией аспекта.
- Время измерено на RTX 4060, не на референсной GTX 1050 Ti; требование ≤ 100 мс на
  референсной конфигурации **не подтверждено**.
- Тип 1А представлен 5 аннотациями — статистики по нему фактически нет.

## Быстрый старт

```powershell
python -m pip install -r solution/requirements.txt
python solution\predict.py --input examples ^
    --weights solution\weights\best_v2.pt ^
    --ocr-weights solution\weights\ocr_v3.pt ^
    --output predictions.csv --device 0
```

В `examples/` лежит одно CC0-изображение для проверки запуска (см.
[`examples/README.md`](examples/README.md)).

Без `--ocr-weights` решение работает как детектор типов и пишет `#` во всех позициях
номера. `--device cpu` запускает инференс без GPU.

## Структура репозитория

```
solution/            инференс: детектор + OCR + постобработка, веса, тесты
  predict.py         CLI: изображения -> CSV организаторов
  ocr.py             CRNN/CTC, подготовка кропа, маска номера
  ocr_data.py        источники данных и аугментации для OCR
  weights/           best_v2.pt (детектор), ocr_v3.pt (OCR)
dataset/             генератор синтетики по ГОСТ, сбор открытых источников,
                     журнал ручной разметки, валидаторы и тесты
training/            скрипты обучения детектора и OCR, оценка на реальных кадрах
docs/                пояснительная записка, отчёты об оценке
```

## Данные

- **Реальные кадры** — только разрешённые источники (Wikimedia Commons: CC0, Public
  domain, CC BY), разметка ручная, журнал `dataset/real_review_inbox/review.csv`.
  Изображения в репозиторий не включены: лицензии смешанные, публикация всего набора
  под CC BY 4.0 требует отдельной проверки каждого файла.
- **Синтетика** — собственный воспроизводимый генератор (`dataset/generator/`,
  фиксированный `--seed`): рендер по ГОСТ Р 50577-2018, вставка в сцену с перспективой,
  освещением, блюром, шумом, дождём/снегом/грязью/бликами, точные `bbox` и `quad`.
  Сгенерировано 6000 кадров / 6630 знаков.

Подробности: [`dataset/README.md`](dataset/README.md),
[`dataset/generator/README.md`](dataset/generator/README.md).

## Обучение

```powershell
# 1. Синтетический датасет (6000 кадров) и детектор
python dataset\generator\build_dataset.py --help
python training\train_detector.py --dataset dataset\generated_4060 --out training\run_plates_4060

# 2. Дообучение детектора на реальных кадрах
python training\build_det_v2_dataset.py
python training\train_det_v2.py --epochs 14

# 3. OCR на реальных кропах + синтетических сценах
python training\train_ocr_v2.py --epochs 14

# 4. Оценка на ручной разметке
python training\eval_real_pipeline.py --weights solution\weights\best_v2.pt ^
    --ocr-weights solution\weights\ocr_v3.pt
```

Все скрипты фиксируют seed и не обращаются к сети. Детектор — YOLOv8n
(3.01 млн параметров), OCR — CRNN + CTC (4 свёрточных блока, BiLSTM 128, вход 64 px).

## Ограничения

- Мало реальных данных: 184 аннотации, из них 5 типа 1А и 32 типа 1Б.
- Сквозная точность ~17 % на ручной разметке — это MVP, а не production-качество.
- Ночь, сильный блюр и грязь остаются основной причиной ошибок OCR.
- Референсная GTX 1050 Ti не проверялась; время измерено на RTX 4060.

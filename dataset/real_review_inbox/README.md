# Кандидаты реальных изображений для ручной проверки

Запусти `dataset/start_annotation.bat` двойным щелчком. По умолчанию откроется
локальная папка `data/commons/images/`; можно размечать и свои локальные
изображения, выбрав другую папку, если в стандартной не найдёшь подходящих.
Программа не отправляет фото в интернет. Исходные снимки не меняются.

## Как разметить фото

1. Мышью обведи рамкой один номер целиком, не захватывая половину машины.
2. Выбери тип кнопкой справа или клавишей `1`/`2`/`3`/`4`:
   - `1` — `type1`, обычный однострочный;
   - `2` — `type1a`, квадратный двухстрочный;
   - `3` — `type1b`, жёлтый;
   - `4` — `other`, другой формат/нецелевой знак.
3. Введи номер латинскими буквами и цифрами. Для нечитаемых символов поставь
   `#`; маска проверяется до сохранения. Для типа 1А вводи номер в обычном
   порядке чтения, слева направо и сверху вниз, например `A123BC77`.
4. Отметь, установлен ли знак на транспортном средстве, и нажми
   **«Добавить разметку»**. Если на фото несколько подходящих номеров, добавь
   их по одному.
5. Если целевого номера нет, нажми **«Отметить: целевого номера нет»**. Не
   нажимай это для неразборчивого номера — обведи его и используй `#`.
6. **«Пропустить»** оставляет фото без разметки; его можно открыть позднее,
   включив «Показывать уже размеченные фото».

Клавиши: `1`–`4` — тип; `V` — переключить «на транспортном средстве»;
`Enter` — добавить рамку и номер; `N` — отметить отсутствие целевого номера;
`Ctrl+S` — сохранить; `←`/`→` — назад/далее. Добавленные аннотации
сохраняются сразу в `dataset/real_review_inbox/review.csv`; выходить можно в
любой момент. При закрытии окна текущий прогресс также сохраняется. Если окно
снова неожиданно закроется, подробности ошибки будут записаны в
`dataset/real_review_inbox/annotation_errors.log`. Уже добавленные номера,
пропуски и отметки «целевого номера нет» сохраняются сразу; после повторного
запуска программа продолжит с первого ещё не обработанного фото. Если окно
упало до нажатия «Добавить разметку», незавершённую рамку для текущего фото
придётся нарисовать заново. При нативном сбое Python в журнал также попадёт
стек для диагностики.

Поля масок: `L` — одна из латинских букв `ABEKMHOPCTYX`, `D` — цифра,
`R` — регион из двух или трёх цифр. Примеры: `type1`/`type1a` —
`A123BC77` или `A123BC777`; `type1b` — `AB12377` или `AB123777`.

Приложение показывает ссылку, лицензию и автора, если они есть в соседнем
`manifest.json`. Лицензия автоматически не подтверждается: галочку проверки
ставь только после самостоятельной проверки условий конкретного файла.
Не используй неразмеченные данные как подтверждённую разметку.

## Источники и разрешения

- Не добавляйте кадры из пабликов ВК, обычных YouTube-видео, соцсетей или
  видеорегистраторских записей без явного разрешения и подходящей лицензии.
  Публичный доступ к посту/видео сам по себе не даёт права скачивать кадры и
  использовать их в датасете. Текущие ограничения проекта исключают соцсети.
- Допустимы только источники, разрешённые правилами проекта, с подтверждённой
  лицензией/разрешением на некоммерческое использование. Неизвестную лицензию
  отмечайте как `ПРОВЕРИТЬ ЛИЦЕНЗИЮ`; такие файлы нельзя включать в обучение.
- Не добавляйте закрытые базы, отладочный набор организаторов, материалы с
  Авито/Дром/Auto.ru или собственные съёмки, запрещённые условиями проекта.
- Не обрезайте и не публикуйте изображение так, чтобы скрыть его исходный
  источник или лицензионные условия. Сохраняйте ссылку на исходную страницу и
  сведения об авторе/атрибуции.

## Организация файлов

Храните изображения под нейтральными именами, не записывайте распознанный
номер в имени файла:

```text
real_review_inbox/
  images/
    candidate_0001.jpg
    candidate_0002.png
  review.csv
```

Для каждого кандидата добавьте строку в `review.csv` с разделителем `;` и
полями:

```text
image;source_url;license;license_verified;attribution;plate_num;plate_type;is_vehicle;manual_review;notes
```

`plate_type` — `type1`, `type1a`, `type1b` или `other`; `is_vehicle` — `1` или
`0`. Не переносите строки в `dataset/meta.csv` и не используйте их для
обучения, пока отдельно не проверены происхождение, лицензия и ручная
разметка. Автоматические предсказания и эвристические фильтры не являются
подтверждённой разметкой.

Не добавляйте сюда видео целиком. Если использование конкретного кадра
разрешено, сохраните только необходимый кадр и зафиксируйте источник и
лицензию. Не загружайте эти изображения в публичные репозитории.

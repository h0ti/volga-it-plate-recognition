# Генератор синтетических ГРЗ

Генератор перенесён как рабочая основа для этапа 3. Он строит номера типов
`type1`, `type1a`, `type1b` и `other`, применяет перспективу и фотоэффекты,
сохраняет bbox/quad, YOLO-метки и `meta.csv`. Сеть и внешние модели не нужны.

## Установка и запуск

Нужен Python 3.10+:

```powershell
python -m pip install -r dataset/generator/requirements.txt
python dataset/generator/build_dataset.py --help
python dataset/generator/build_dataset.py --out dataset/generated --synthetic 10 --seed 20260903
```

По умолчанию фоны создаются процедурно. `--bg-dir` позволяет использовать
папку пользовательских фотографий, только если их лицензии и право на
производные изображения проверены вручную. Генератор не скачивает фотографии
и не считает файлы из соседнего проекта автоматически разрешёнными.

Чтобы не затереть заготовку `dataset/meta.csv`, выход по умолчанию изолирован в
`dataset/generated/`; скрипт откажется писать в непустой каталог. Выход содержит
`images/synthetic/`, `labels/` и собственный `meta.csv`. После проверки его
можно объединить с итоговым набором отдельным валидируемым шагом; этот генератор
не перезаписывает и не объединяет текущий `dataset/meta.csv`.

`--seed` фиксирует случайные значения для воспроизводимости. Пример с 10 кадрами
предназначен для локальной проверки; полный запуск с 6 000 кадрами может занять
заметное время и требует свободного места на диске.
Для обучения детектора по умолчанию 10% кадров — фоновые негативы без знаков;
для них в `labels/` создаются пустые файлы. Долю можно менять через
`--negative-fraction` (от 0 до 0.4).

На RTX-ПК скрипт `training/train_semifinal.bat` генерирует выборку, обучает
YOLO-детектор и отдельно CRNN/CTC OCR. Это кандидаты моделей на синтетике, не
подтверждённый результат на реальных кадрах.

## Ограничения и проверка

Разметка сгенерирована программно и относится только к синтетическим кадрам;
она не является ручной разметкой реальных изображений. Строки `other` не
содержат распознанный номер. Реальные фото, подписи к ним и лицензии не
включаются автоматически.

Рендер использует совместимые с PIL системные шрифты, найденные в Windows.
Шрифты не копируются в проект. На другой ОС доступный набор шрифтов будет
отличаться и может изменить пиксели результата; фиксированный seed сам по себе
не гарантирует идентичный вывод между системами. Поэтому поле `license` для
синтетических файлов пока честно содержит `ПРОВЕРИТЬ ЛИЦЕНЗИЮ`: проверьте
условия использования шрифтов и только затем устанавливайте лицензию набора.

Перед обучением проверьте несколько кадров и меток, затем валидируйте весь
датасет скриптом формата соревнования. Не выдавайте программные эвристики за
ручную проверку. Политика лицензии всего датасета остаётся описанной в
`dataset/LICENSE`; этот README сам по себе не меняет её.

# Инференс решения

Офлайн-пайплайн: YOLOv8n находит знак и его тип, CRNN/CTC читает номер,
детерминированная постобработка приводит строку к маске ГОСТ и формату CSV
организаторов.

## Запуск

```powershell
python -m pip install -r solution/requirements.txt
python solution\predict.py --input path\to\images ^
    --weights solution\weights\best_v2.pt ^
    --ocr-weights solution\weights\ocr_v3.pt ^
    --output predictions.csv --device 0
```

- `--device cpu` — инференс без GPU (медленнее, но полностью офлайн).
- `--imgsz 640` — размер входа детектора; `--conf 0.25` — порог детекций.
- Без `--ocr-weights` решение работает как детектор типов: во всех позициях номера
  выводится `#`.
- Веса загружаются только из указанных локальных файлов, сеть не используется.

Формат выхода — ровно одна строка на изображение:

```
image;plate_num;plate_type;confidence
```

## Как принимаются решения

1. Из всех детекций выбирается лучшая целевая (`type1/type1a/type1b`); если целевых
   нет — `other` с пустым номером.
2. Тип уточняется по геометрии рамки (квадратная → 1А, широкая → 1/1Б) и по доле
   жёлтых пикселей HSV; при спорной геометрии OCR пробует обе раскладки.
3. OCR запускается на нескольких кропах (разные отступы + нормализация аспекта), из
   результатов выбирается самый читаемый.
4. Недопустимые для позиции символы заменяются `#`, короткий хвост добивается `#`.
   Длина 8/9 (тип 1, 1А) и 7/8 (1Б) сохраняется: код региона бывает двух- и трёхзначным.
5. `confidence` — score детектора, умноженный на среднюю вероятность символов CTC;
   для `other` номер пуст.

## Метрики

См. корневой [`README.md`](../README.md) и [`docs/ЗАПИСКА.md`](../docs/ЗАПИСКА.md).
Кратко: детекция 95.7 % (IoU ≥ 0.5) на 184 ручных аннотациях, тип 99.4 % среди
найденных, OCR 36.4 % точных номеров на эталонных кропах (22.5 % на 40 отложенных
кадрах), сквозное совпадение 32.9 % на 164 кадрах.

Это MVP: цифры получены на собственной ручной разметке, независимого теста
организаторов нет.
